VIEWS

We used the Course domain model.

View 1 - Function-Based View: Manual HttpResponse
Name: course_summary_view

Displays a summary of Course objects. The view manually loads
courses/course_summary.html using loader.get_template(), manually
renders the context, and wraps the result in HttpResponse.

URL:
/courses/summary/


View 2 - Function-Based View: render() Shortcut
Name: course_list_view

Displays a list of all Course objects. The view manually queries
Course.objects.all(), places the queryset into a context dictionary,
and renders courses/course_list.html using Django's render()
shortcut.

URL:
/courses/

View 3 - Base Class-Based View
Name: CourseOverviewView

Displays a custom overview of Course objects. The class inherits
from django.views.View, implements get(), manually queries the
Course model, creates a context dictionary, and renders the course
overview template.

URL:
/courses/overview/


View 4 - Generic Class-Based View
Name: CourseDetailView

Displays the details of one Course. The class inherits from
Django's DetailView, defines model = Course, specifies a template,
and uses "course" as the context object name.

URL:
/courses/<course_id>/
